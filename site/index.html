Ready for a million rows.

A small, open-source viewer for PostgreSQL®: pages through million-row tables, and read-only by default.

On a local database, Slonview exports a 1,000,000-row table to CSV in about 0.44 s, byte-identical to psql \copy.

Look first. Write on purpose.

Download for macOS Linux and Windows builds

Free under MIT or Apache-2.0. Built with Tauri 2, Rust and React. macOS first.

What it does

Quick on big tables.

  • Tables load 500 rows at a time, with keyset paging when a primary key exists.
  • Exports stream straight to disk. A 1,000,000-row table took about 0.44 s on a local PostgreSQL 18.4, byte-identical to psql \copy.
  • Esc cancels a running query on the server.

Read-only by default.

  • New connections open read-only READ-ONLY, and the PostgreSQL server enforces it, so a stray DELETE is rejected.
  • To write, turn on Allow writes for that connection. A red WRITE badge stays on while it's on.
  • Read-only is a default, not a lock. For a hard guarantee, connect as a read-only role.

Free, with no catches.

  • MIT or Apache-2.0. No paid tier, no tab limits.
  • Copy as CSV, TSV, JSON or INSERT.
  • No telemetry: Slonview only talks to the PostgreSQL servers you configure.
  • Passwords stay in the OS credential store (Keychain on macOS).

A SQL editor that knows your schema.

Autocomplete for tables, and for columns after an alias such as o.. Run one statement or all of them, keep per-query history, and read query plans as a tree with Explain.

Also: several connections at once, SSH tunnels, TLS up to verify-full, a per-connection time zone, and reviewable row edits on connections where you allowed writes.

Install

On a Mac with Homebrew:

brew install --cask tomasdewantoro/tap/slonview

Or download the .dmg for your Mac (Apple Silicon or Intel), the .AppImage or .deb for Linux, or the .msi for Windows from the latest release. Mac builds are signed and notarized by Apple. Windows builds aren't signed, so SmartScreen asks once. Or build from source:

git clone https://github.com/tomasdewantoro/slonview
cd slonview && pnpm install && pnpm tauri build
